# Lyra — Engineering Package

> This is the original engineering package. Its use of “open source” predates the user's clarified requirement that commercial use and paid resale are prohibited. The current distribution intent is public, source-available, noncommercial; see the repository [LICENSE](../LICENSE) and [implementation plan](IMPLEMENTATION_PLAN.md).

This archive contains the initial engineering package for Lyra:

- `PRD.md` — product requirements, UX, roadmap, safety, privacy, testing and acceptance criteria.
- `TECH_STACK.md` — native macOS stack, module boundaries, protocols, data flow and implementation order.
- `AGENTS.md` — instructions for coding agents working in the repository.

## Product thesis

**Gaze = where. Voice = what.**

The base system is deterministic and works without AI. AI integrations are layered on top through validated structured intents.
